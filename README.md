# Кто сказал?

Игра для детей 2–6 лет: войлочные зверята и машинки, их голоса и звуки.
Работает в браузере телефона и без интернета (после первого запуска).

## Что внутри

- **Пять игр:** «Кто сказал?» (послушай и найди), «Послушать», «Чей голос?» (найди колокольчик),
  «Найди пару» (память по голосам), «Кто где живёт» (отведи домой).
- **98 игрушек** в шести наборах: Домашние, Питомцы, Лесные, Зоопарк, Море, Машины — и «Вперемешку».
  У каждого набора свой войлочный мир-фон.
- **Голос Ксении (Silero):** вопросы, похвала, факты, имя ребёнка. У 64 игрушек — настоящие записи голосов.
- **Награды:** наклейки и альбом, гость дня, праздник за собранный набор, звёзды на наборах.
- **Для взрослых** (удерживать кнопку сложности 2,5 с): сложность, имя, наборы, факты,
  лимит времени, успехи ребёнка, громкость, загрузка для игры без интернета.

## Запуск

```bash
npm install
npm run dev            # http://localhost:8080
npm run build          # итоговая сборка
```

## Проверка

Тесты проходят каждую игру в браузере телефона, проверяют «Назад», удержание настроек,
родительский уголок, паузу и двойные тапы.

```bash
npm run dev &                        # игра на http://127.0.0.1:8080/
npx playwright install chromium      # один раз
npm run test:e2e

# игра без интернета (нужна итоговая сборка с service worker):
npm run build && npm run preview:restart
OFFLINE=1 BASE_URL=http://127.0.0.1:8081/ npm run test:e2e
```

## Как добавить

- **Зверя:** строка в `src/lib/who-said/content.ts` (и факт в `FACTS`), картинка — лист Codex
  в `assets/felt-sheets` + `tools/cut-felt.py`, звук — `tools/cut-sound.py`,
  озвучка — `python3 tools/make-voice.py <v5_ru.pt> only-missing`, наклейка — `tools/make-stickers.py`.
- **Имя ребёнка:** строка в `src/lib/who-said/names.ts`, затем `make-voice.py … only-missing`.
- После замены любых картинок или звуков в `public/` ничего делать не нужно: `npm run build`
  сам пересчитывает метки версий, и телефоны скачают новое.

Источники звуков, голоса и музыки и их лицензии — в `assets/SOUND-CREDITS.md`
(часть разрешена только для личного использования).
