## Голос

Фразы «Где …?», «Это …!», «Молодец!», «Попробуй ещё!» синтезированы
Silero TTS v5 (ru), голос xenia, скриптом `tools/make-voice.py`.
Модели Silero распространяются по лицензии CC BY-NC 4.0 — подходит для
личного некоммерческого использования. Для коммерческой версии голос нужно
заменить (например, на Vosk TTS, Apache-2.0).
Добавили животное в `content.ts` — запустите скрипт с флагом only-missing,
он озвучит только новое.
